# Kalio 1.1.0 — release candidate

Status: draft preparation; stable publication is blocked.

## Integrated work

- Current main release tooling, Docker distribution and Remote security fixes.
- Runtime hardening, durable context/approval evidence and workflow execution scope.
- Remote mobile readability, current approvals and reconnect/private-device isolation.
- Native ChatGPT image generation/editing integration and image provider capability settings.
- Experimental Apple Silicon macOS source installer and local CLI updates.
- Windows CMD argument preservation, process ownership safeguards and corrected cross-platform regression fixtures.

## Platforms

| Platform | Distribution | Boundary |
| --- | --- | --- |
| Windows x64 | Node/Bun runtime archives and optional NSIS desktop shell | Native build/smoke workflow required before release |
| Linux x64 | Node/Bun runtime archives, AppImage and DEB | Native build/smoke workflow required before release |
| macOS Apple Silicon | Experimental source archive and source installer | Native source build/start/stop smoke; no DMG/notarization |

The source workflow uses isolated data and random ports with the mock provider.
An archive build or mock smoke does not prove a real provider, model quality,
cross-version upgrades or production deployment. The prior Mac agent reported
installation and a same-revision update on macOS 26.3 arm64.

## Required before stable publication

- [P1] Compose and verify accepted-goal runtime activation. The public runtime
  currently omits trusted goal protocol, durable visit, worker-attempt and
  terminal callbacks. The retained `architecture-runtime.goal-integration.spec.ts`
  fails with `CONTRACT_VIOLATION`; do not bypass it or fabricate execution proof.
- [P2] Complete native platform CI and inspect produced artifacts/checksums.
- [P2] Obtain shared-contract PR review and verify a real cross-version macOS
  update before describing macOS support as stable.

Updates preserve existing application data. Keep the database and credential
encryption key together. Managed source stacks refuse destructive stop/restart
when saved process ownership cannot be established; inspect stale legacy state
instead of killing the current listener on a saved port.
